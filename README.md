# 🎓 Student Management System — SQL Final Project

A relational database project built with SQL to manage departments, instructors, courses, students, and enrollments.

## 📌 Overview

This project demonstrates how a normalized relational database can be designed and queried for an educational institution.

The database includes:

- Departments
- Instructors
- Courses
- Students
- Enrollments

## ✨ Features

- Database and table creation
- Primary and foreign keys
- Sample data insertion
- CRUD operations
- Filtering and aggregation
- INNER JOIN and LEFT JOIN queries
- Subqueries
- Conditional logic with `CASE`
- Date extraction and string functions
- Running totals using window functions

## 📊 Analytical Queries

The SQL script includes queries for:

- Students enrolled after a specific year
- Courses by department
- Student counts by course and department
- Students taking multiple courses
- Average course credits
- Maximum instructor salary by department
- Student-course relationships
- Running enrollment totals
- Student status classification

## 🗂️ Database Structure

```text
departments
    ├── instructors
    └── courses
          └── enrollments ─── students
```

## 📄 Main File

- `Final_Project.sql` — complete database setup, sample data, CRUD operations, and analytical queries.
